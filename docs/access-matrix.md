## Політика відмов

Для головної action authenticated non-owner (інший Reporter) отримує 404 Not Found, така сама відповідь, як для неіснуючого інциденту. Анонімний запит отримує 401. Причина вибору 404: сервер не розкриває, що чужий інцидент існує, тому за кодом відповіді не можна перебирати чужі identifier. Власник і Analyst отримують 200. Administrator не має опублікованого права читати деталі, тому також отримує 404.
